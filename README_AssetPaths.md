# VST3 / AU アセットの場所を設定する

PCMサンプルとパッチバンクの場所は、プラグイン画面右上の **Settings** を開き、**Asset folders** から指定できます。

- **PCM folder...** で `0.wav` ～ `127.wav` を含むフォルダを選びます。確認のあとPCMデータを読み込み直し、ドラムキットをそのフォルダの内容で作り直します（画面で割り当てたノートは置き換わります）。
- **Patch folder...** で `0.json` ～ `127.json` を含むフォルダを選びます。確認のあとパッチバンクを読み込み直します（JSONに保存していないパッチの編集は消えます）。
- 選択したパスはプラグイン状態に保存されるため、DAWのプロジェクト／プラグインプリセットを保存すると次回の復元時にも引き継がれます。

## 初期値

設定が保存されていない場合は、次の環境変数を順に参照します。

| 環境変数 | 指定するディレクトリ | 内容 |
| --- | --- | --- |
| `3HSPLUG_PCM_PATH` | PCMサンプルのディレクトリ | `0.wav` ～ `127.wav` |
| `3HSPLUG_PATCHES_PATH` | パッチバンクのディレクトリ | `0.json` ～ `127.json` |

どちらも未設定の場合、PCMは `./pcm/`、パッチは `patches/` を使います（ホストの作業ディレクトリ基準）。環境変数はプラグイン生成時に読み込まれます。AUで環境変数を渡せない場合は、Settingsの Asset folders から指定してください。

## ファイル形式

- PCMサンプル名はMIDIノート番号に対応する数値の `.wav` ファイルです。
- パッチJSONはバンク番号の `.json` ファイルです。各ファイルには `patches` 配列が必要です。
