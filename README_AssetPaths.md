# VST3 / AU アセットの場所を設定する

PCMサンプルとパッチバンクの場所は、プラグイン画面の **Settings** メニューから指定できます。

- **Choose PCM samples folder...** で `0.wav` ～ `127.wav` を含むフォルダを選びます。選択するとPCMデータを読み込み直し、音源に反映します。
- **Choose patch banks folder...** で `0.json` ～ `127.json` を含むフォルダを選びます。選択するとパッチバンクを読み込み直します。
- 選択したパスはプラグイン状態に保存されるため、DAWのプロジェクト／プラグインプリセットを保存すると次回の復元時にも引き継がれます。

## 初期値

設定が保存されていない場合は、次の環境変数を順に参照します。

| 環境変数 | 指定するディレクトリ | 内容 |
| --- | --- | --- |
| `3HSPLUG_PCM_PATH` | PCMサンプルのディレクトリ | `0.wav` ～ `127.wav` |
| `3HSPLUG_PATCHES_PATH` | パッチバンクのディレクトリ | `0.json` ～ `127.json` |

どちらも未設定の場合、PCMは `./pcm/`、パッチは `patches/` を使います（ホストの作業ディレクトリ基準）。環境変数はプラグイン生成時に読み込まれます。AUで環境変数を渡せない場合は、Settingsメニューから指定してください。

## ファイル形式

- PCMサンプル名はMIDIノート番号に対応する数値の `.wav` ファイルです。
- パッチJSONはバンク番号の `.json` ファイルです。各ファイルには `patches` 配列が必要です。
